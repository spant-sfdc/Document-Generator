Production Guidance — Building in Google Slides / PowerPoint / Figma

GOOGLE SLIDES
  • File → Page Setup → Custom: 1920 × 1080px
  • Use Inter (Google Fonts) — import via Extensis Fonts add-on
  • Slide transition: Fade, 0.3 sec, all slides
  • Element animations: Appear or Fade in only — avoid Fly
  • Export as MP4 → File → Download → MP4 (for video sync)
FIGMA (recommended for polish)
  • Frame size: 1920 × 1080, auto-layout for responsive cards
  • Use Figma Prototype mode for transitions
  • Export each slide as PNG (300dpi) for fallback
  • Use Figma Presentation mode for live demos
  • Component library: Phosphor Icons or Lucide Icons plugin
ICON RECOMMENDATIONS
  • Lucide Icons — clean, minimal, free (lucide.dev)
  • Phosphor Icons — duotone style for architecture slides
  • Salesforce Lightning Icons — for record/object slides
  • Minimum icon size: 48px render, scale to slide proportionally
  • Consistent icon weight across all slides (no mixing stroke weights)
VIDEO SYNC GUIDANCE
  • Slides support the demo video — not a replacement
  • Switch slides at section boundaries in the narration script
  • Hold Slide 4 (use case) during Section 3 admin config flow
  • Switch to Slide 7 (engine) during Section 5 generation narration
  • Slide 10 (outro) stays on screen for entire Section 8 narration
